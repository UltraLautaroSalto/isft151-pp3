# "AsistE-OS"

### isft151-pp3
(Proyecto de "SISTEMA DE CONTOL DE ASISTENCIAS ESCOLARES")

Los objetivos principales de AsistE-OS es facilitar el control sobre las asistencias de los estudiantes, permitir que los docentes vean la información completa de dichas asistencias (Incluyendo las faltas o las tardanzas y sus razones) y que los administradores puedan hacer los cambios necesario en cualquier momento de manera sencilla (Ingresar, Asignar, remover y modificar alumnos, docentes y clases).

Los Roles que va a tener el proyecto son los siguientes:
- Estudiantes
- Docentes
- Administradores
