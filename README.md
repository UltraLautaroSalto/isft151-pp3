# isft151-pp3
Proyecto de "SISTEMA DE CONTOL DE ASISTENCIAS ESCOLARES"

Los objetivos principales de este proyecto es controlar las asistencias de los estudiantes, permitir que los docentes vean la información completa de dichas asistencias y que los administradores puedan hacer los cambios necesario en cualquier momento de manera sencilla.

Los Roles que va a tener el proyecto son los siguientes:
- Estudiantes
- Docentes
- Administradores
